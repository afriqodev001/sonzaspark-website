# SonzaSpark — Global brand site

SonzaSpark is a hands-on STEM program for young builders. Developed by HyracTech, operated in Tanzania by Afriqo E-Learning Tanzania.

**Live:** sonzaspark.com (planned)

## What this site is
- The global brand story
- A project showcase
- A country selector routing visitors to local operator sites (Tanzania → afriqoelearningtz.com)

## What this site is NOT
- Not a Tanzania booking/enrollment page (that lives on afriqoelearningtz.com)
- Not an online course platform
- Not a sponsor portal

## Local dev

From the workspace root:
```bash
node tools/serve.mjs sonzaspark 3001
node tools/screenshot.mjs http://localhost:3001 label
```
